# ADR 0005: System-site-packages virtual environment

## Status

Accepted

## Context

Picamera2 and its libcamera integration are installed from Raspberry Pi OS
packages by `scripts/install.sh`. The editable project and development tools
still benefit from a local virtual environment.

## Decision

Create `.venv` with `python3 -m venv --system-site-packages`. Install PiPrints
and its development extras into that environment while using the Raspberry Pi
OS-managed Picamera2 package.

## Consequences

The virtual environment can import the system-provided camera integration
without treating it as an ordinary pip dependency. Developers should use the
setup script or preserve this option when recreating `.venv` on the Raspberry
Pi.
